# D3.js exercises

Small HTML pages that introduce D3 step by step, ending in an interactive scatter plot. They use D3 v7 and need no installation or build step.

## How to run

The pages must be served by a local web server, started from inside the `viz/` folder:

```bash
cd viz
python3 -m http.server 8000
```

Then open <http://localhost:8000/> in a browser and click a file in the list. Stop the server with Ctrl+C.

After editing a file, save it and reload the page in the browser. The server does not need a restart.
